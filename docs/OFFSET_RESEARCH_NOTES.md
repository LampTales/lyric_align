# Offset 研究记录

本文记录 2026-09-15 至 2026-09-16 的 offset 实验现象，供后续改进算法时参考。这里的结论来自当前代码和样本实验，不是新的自动化规则。

## 当前实现

默认流程先用人声 stem 的 16 kHz 单声道 RMS（30 ms 窗、10 ms 步长）计算整曲 offset 分数，再用持续人声和长静音边界约束候选。能量分数仍是每句等权的局部对比度平均值，搜索范围默认为 -2000 到 +2000 ms，步长 40 ms。边界锚点只在满足长静音、持续活动、歌词关联唯一等条件时建立；冲突时返回 0/uncertain。边界检查关闭且声学验证关闭时，恢复原来的能量评分和接受门限。

可选 CTC 声学验证默认关闭。此前实验显示它会误拒用户听音确认正确的田中愛愛愛子 +880 ms，因此暂不把它作为默认决策依据。

## 关键样本

### Reol《煽げや尊し》

旧能量流程在混合音频/人声实验中选择 -1680 ms。人声开头约 3.8 秒前是长静音，首句原标注从 3.510 秒开始；-1680 ms 会把首句移到约 1.830 秒，明显借用了后续人声或伴奏能量。新边界流程检测到首个持续人声约 3.83 秒，并在后段检测到另一个长间隔后的起唱约 82.71 秒。两个锚点允许区间分别约为 [-480, 1120] 和 [-2256, -656] ms，交集为空，因此最终 offset 为 0，阻止了整曲错误提前。

0 ms 并不代表首句已经精确。当前产物首句的活动起点约 3.88 秒，原句首为 3.51 秒，歌词/扫色仍可能提前约 0.32–0.37 秒。首句 CTC 分数约 -1.55，略低于默认 -1.5 门限；活动置信度约 0.31，也低于用于缩小 CTC 窗口的 0.45 门限。首句因此使用原句窗口和回退插值。这个现象说明 offset 防错与句内起唱修正是两个不同问题，不能用“offset=0”解释为逐字时间已准确。

当前 Reol 对齐中大量句子还触发了 CTC 零时长修补；修补保证显示顺序和可见时长，但不等同于声学证据。后续应单独评估活动置信度、CTC 质量门限和回退起点是否需要调整。

### Noah Kahan《False Confidence》

旧流程的最高能量候选为 +960 ms，但局部峰值差只有 0.005755，小于 0.01，所以旧流程返回 0。新流程由开头和间奏边界得到允许交集约 [1130, 1560] ms，在交集内选择 +1240 ms；用户听音确认新偏移正确。

这个样本说明能量评分不是实现错误，但存在目标函数盲点：它只衡量局部能量上升，不确认歌词身份；所有句子等权平均，伴奏重拍或偶然能量峰可能成为全局最高峰；当最高峰不够稳定时，旧流程直接回到 0，也不会在有边界证据的范围内重新选择候选。边界约束因此不仅能否决错误候选，也可能把旧的 0 变成正确的非零候选。

### 田中愛愛愛子

用户听音确认 +880 ms 正确。默认边界流程没有找到可靠长静音锚点，因此保留 +880 ms。实验性 CTC 验证曾否决该正确候选，说明当前短窗声学比较不够可靠，必须保持默认关闭。

## 正式曲库副本实验

正式 `deploy/cloudmusic2ktv-backend/docker-data/outputs` 曾被完整复制到临时实验目录；deploy 原目录未修改。对比实验按用户要求提前停止，完成 18 首（779 句），第 19 首中断，未完成歌曲未计入统计。每首只做一次人声分离，旧、新代码使用相同 WAV，并分别运行 reading、offset、activity、CTC 和产物后处理。

- 16 首的 offset 和逐句产物保持一致。
- Reol：-1680 → 0 ms；CTC 统计由 58/3（CTC/fallback）变为 60/1。
- False Confidence：0 → +1240 ms；这是边界筛选后重新选择幸存候选的结果，已由用户听音确认。
- 默认边界计算额外耗时中位约 1.08 ms/首，完整对齐新旧耗时差中位约 +4.9 ms，处于执行波动量级。
- 人声分离中位约 69 秒；新流程已有 stem 时完整对齐中位约 13.3 秒；相同配置缓存命中中位约 7.4 ms。
- 实验性声学验证实际执行的 12 首中 2 首接受、10 首否决，中位约 2.38 秒；不能把这个接受率当作准确率。

实验副本和运行日志已清理，只保留本研究记录。样本目录中原有的 Reol、田中和边界验证产物仍按此前安排保留。

## 后续设计方向

当前实现先作为默认实现使用。后续若继续设计，优先考虑：

1. 对能量候选加入跨段一致性和峰稳定性，而不是只取全局最高分。
2. 明确区分“全局 offset”与“句内起唱偏移”；不要用全局 offset 解决 Reol 首句局部提前。
3. 重新评估活动置信度的定义和校准，尤其是 0.35/0.45 两个使用位置。
4. 评估 CTC 质量门限和零时长修补对显示起点的影响。
5. 若改变候选选择策略，继续保留 Reol、False Confidence、田中三个回归样本。
